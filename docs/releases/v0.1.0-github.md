# Codex Command Center v0.1.0

Codex Command Center v0.1.0 is the first public release of a Windows-first, local-first desktop workspace for organizing Codex engineering work. It helps keep projects, tasks, Codex sessions, Git changes, Skills, and MCP configuration visible in one focused desktop app.

## Highlights

- Organize local projects and engineering tasks.
- Discover local Codex sessions, link them to tasks, and resume selected sessions.
- Review Git branch state, changed files, and readable diffs.
- View Codex CLI, Skills, and MCP environment information.
- Store application state locally on the desktop.
- Run as a Windows-first Tauri desktop application.

## Downloads

- `Codex Command Center_0.1.0_x64-setup.exe`  
  Recommended installer for most Windows users.

- `Codex Command Center_0.1.0_x64_en-US.msi`  
  MSI package for users or environments that prefer MSI deployment.

- `codex-command-center.exe`  
  Standalone application executable.

- `SHA256SUMS.txt`  
  SHA-256 checksums for release binaries.

## Requirements

- Windows 11 is the primary supported platform.
- Git on `PATH` is required for Git workflows.
- Codex CLI on `PATH` is required for Codex launch and resume workflows.

## Known limitations

- Binaries are currently unsigned.
- Windows is the documented release target for v0.1.0.
- The app does not provide cloud sync, accounts, telemetry, or collaboration features.
