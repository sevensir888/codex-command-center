# Codex Command Center v0.1.0 Release Notes

## Overview

Codex Command Center v0.1.0 is the first public release of a Windows-first local desktop workspace that organizes Codex-based engineering work across projects, tasks, Codex sessions, Git changes, Skills, and MCP configuration.

The public release page is available at https://github.com/sevensir888/codex-command-center/releases/tag/v0.1.0.

## Major capabilities

- Register local development folders as projects.
- Track engineering tasks with Planned, Active, Completed, and Blocked statuses.
- Discover local Codex session metadata and link sessions to tasks.
- Launch Codex for a task and resume selected sessions through the local Codex CLI.
- Inspect branch, staged files, unstaged files, and readable Git diffs.
- View detected Codex CLI, local configuration previews, Skills, and MCP server summaries.
- Store application state locally under the user's local application data directory.

## Platform

- Primary release target: Windows 11.
- Desktop runtime: Tauri 2.
- Frontend: React and TypeScript.
- Native layer: Rust.

## Installation

The v0.1.0 release publishes three Windows binary options:

- `Codex Command Center_0.1.0_x64-setup.exe`: recommended for most Windows users as the normal interactive installer.
- `Codex Command Center_0.1.0_x64_en-US.msi`: useful for users or environments that prefer MSI-based installation or deployment.
- `codex-command-center.exe`: standalone Tauri application executable that can run directly without a normal installer.

For source builds:

```bash
npm ci
npm run build
npm run tauri:build
```

## Prerequisites

- Windows 11 is the primary supported platform.
- Git on `PATH` for Git review.
- Codex CLI on `PATH` for launch and resume actions.
- Node.js 20 or newer, Rust, and Cargo are required only for source builds.

## Known limitations

- Windows installers are unsigned unless the maintainer later adds code signing.
- The app is local-first and does not provide cloud synchronization, accounts, telemetry, or collaboration features.
- Windows 11 is the documented release target for v0.1.0; other desktop platforms are not currently published as supported release targets.
