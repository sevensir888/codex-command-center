# Codex Command Center v0.1.0 Release Candidate Notes

## Overview

Codex Command Center v0.1.0 is the first public release candidate for a Windows-first local desktop workspace that organizes Codex-based engineering work across projects, tasks, Codex sessions, Git changes, Skills, and MCP configuration.

This file is source material for a later GitHub Release. It does not mean the release has already been published.

## Major capabilities

- Register local development folders as projects.
- Track engineering tasks with Planned, Active, Completed, and Blocked statuses.
- Discover local Codex session metadata and link sessions to tasks.
- Launch Codex for a task and resume selected sessions through the local Codex CLI.
- Inspect branch, staged files, unstaged files, and readable Git diffs.
- View detected Codex CLI, local configuration previews, Skills, and MCP server summaries.
- Store application state locally under the user's local application data directory.

## Platform

- Primary release target: Windows 11.
- Desktop runtime: Tauri 2.
- Frontend: React and TypeScript.
- Native layer: Rust.

## Installation expectations

Tagged releases are expected to publish Windows artifacts generated by the release workflow. The verified Windows v0.1.0 build produces an NSIS setup executable, an MSI installer, and the standalone Tauri application executable.

For source builds:

```bash
npm ci
npm run build
npm run tauri:build
```

## Prerequisites

- Node.js 20 or newer.
- Rust and Cargo for Tauri desktop builds.
- Git on `PATH` for Git review.
- Codex CLI on `PATH` for launch and resume actions.

## Known limitations

- Windows installers are unsigned unless the maintainer later adds code signing.
- The app is local-first and does not provide cloud synchronization, accounts, telemetry, or collaboration features.
- Other desktop platforms are not documented as release targets for this release candidate.
