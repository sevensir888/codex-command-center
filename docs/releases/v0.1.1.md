# Codex Command Center v0.1.1 Release Notes

## Overview

Codex Command Center v0.1.1 is a focused reliability and maintenance update for the Windows desktop application.

## Highlights

### More resilient local state storage

Local application state is no longer written by directly truncating the primary `state.json` file.

The persistence path now:

- writes new state to a same-directory temporary file
- validates serialized state before replacement
- synchronizes writes before replacement
- keeps one rolling backup of the previous valid state
- can recover from a valid backup when the primary state file is corrupted

On Windows, replacement of an existing state file uses the platform replacement API rather than relying on generic rename behavior.

### Regression coverage

Rust regression tests cover:

- first save behavior
- subsequent save behavior and rolling backup creation
- corrupted-primary recovery from a valid backup
- preservation of a valid backup
- invalid primary plus invalid backup behavior
- first-run missing state behavior
- state serialization round trip behavior
- backup-write failure behavior
- prevention of invalid serialized state replacing the primary file

### Maintenance

- Updated GitHub Actions workflows to Node.js 24-compatible action versions.
- Refined routine Dependabot updates to minor and patch releases.
- Updated validated frontend and Rust dependencies.
- Clarified community contribution routing.

## Downloads

The v0.1.1 Windows release is expected to publish the same artifact classes as v0.1.0:

- `Codex Command Center_0.1.1_x64-setup.exe`: recommended for most Windows users as the normal interactive installer.
- `Codex Command Center_0.1.1_x64_en-US.msi`: useful for users or environments that prefer MSI-based installation or deployment.
- `codex-command-center.exe`: standalone Tauri application executable that can run directly without a normal installer.
- `SHA256SUMS.txt` containing SHA-256 checksums for release binaries

## Requirements

- Windows 11 is the primary supported platform.
- Git on `PATH` is required for Git workflows.
- Codex CLI on `PATH` is required for Codex launch and resume workflows.
- Node.js 24 is the validated source-development and production-build version; Rust and Cargo are also required for native builds.

## Compatibility

The state schema and existing local state file location are unchanged. Existing v0.1.0 local state should remain compatible.

## Known limitations

- Windows binaries are currently unsigned.
- The app is local-first and does not provide cloud synchronization, accounts, telemetry, or collaboration features.
- Windows 11 is the documented release target for v0.1.1; other desktop platforms are not currently published as supported release targets.
