# Code of Conduct

## Our pledge

Participants in Codex Command Center are expected to help keep project spaces respectful, focused, and useful for open-source collaboration.

## Expected behavior

- Be respectful of differing experience levels and viewpoints.
- Keep issues and pull requests focused on the project.
- Provide clear reproduction steps, evidence, and technical context when reporting problems.
- Remove secrets, tokens, private repository content, and personal information from shared logs or screenshots.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing another person's private information.
- Posting secrets, exploit details, or sensitive local data in public project spaces.
- Persistent off-topic promotion or disruption.

## Enforcement

The maintainer may edit, hide, or remove comments and may limit participation when behavior harms the project. For sensitive conduct issues, use the most private GitHub contact mechanism available for the repository.
